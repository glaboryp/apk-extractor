# Política de privacidad de APK Extractor

**Última actualización: 22 de octubre de 2026**

APK Extractor es una aplicación Android que permite consultar las aplicaciones
instaladas en el dispositivo, extraer sus archivos APK y facilitar la
instalación de paquetes APK compatibles.

## Datos que procesa la aplicación

APK Extractor puede acceder localmente a:

- La lista de aplicaciones instaladas en el dispositivo.
- Los nombres de paquete, nombres visibles y archivos APK asociados.
- Los archivos que la persona usuaria selecciona mediante el selector de
  archivos del sistema.
- Los archivos APK que la persona usuaria decide guardar o compartir.

## Uso de los datos

Estos datos se utilizan exclusivamente para proporcionar las funciones
principales de la aplicación:

- Mostrar las aplicaciones instaladas.
- Extraer APK y paquetes con splits.
- Guardar archivos extraídos en el dispositivo.
- Compartir archivos cuando la persona usuaria lo solicita.
- Leer e instalar paquetes APK compatibles cuando la persona usuaria lo
  solicita.

El procesamiento se realiza localmente en el dispositivo.

## Recopilación y envío de datos

APK Extractor no recopila ni envía datos personales a servidores propios o de
terceros.

La aplicación no utiliza:

- Cuentas de usuario.
- Publicidad.
- Analítica.
- Seguimiento.
- Ubicación.
- Contactos.
- Cámara.
- Micrófono.
- Identificadores publicitarios.

La aplicación no transmite la información de las aplicaciones instaladas a
servidores externos.

## Compartición de archivos

Cuando la persona usuaria utiliza la función de compartir, Android muestra el
selector de aplicaciones del sistema. El archivo se comparte únicamente con
la aplicación y el destinatario que la persona usuaria elija.

## Permisos

La aplicación solicita permisos relacionados con sus funciones principales:

- Consultar aplicaciones instaladas, para mostrar la lista de aplicaciones
  que se pueden extraer.
- Instalar paquetes desde fuentes externas, para instalar archivos APK y
  paquetes compatibles.
- Acceder a notificaciones, cuando es necesario para mostrar el progreso de
  una extracción en segundo plano.

Estos permisos no se utilizan para recopilar ni transmitir información
personal.

## Conservación y eliminación

Los archivos extraídos permanecen en el dispositivo hasta que la persona
usuaria los elimine. APK Extractor no conserva copias en servidores externos.

## Cambios en esta política

Esta política puede actualizarse si cambian las funciones de la aplicación o
sus prácticas de privacidad. La fecha de actualización se modificará cuando
se publique una nueva versión.
